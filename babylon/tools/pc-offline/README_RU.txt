Battlefield — Windows x64, автономная экспериментальная сборка

1. Полностью распакуйте ZIP в отдельную папку.
2. Откройте START_BATTLEFIELD.cmd. Установка Node.js не нужна.
3. В браузере откроется http://127.0.0.1:8877/babylon/index.html. Нажмите кнопку старта игры.
4. Для завершения закройте окно локального сервера.

Не открывайте index.html двойным щелчком: для загрузки 3D-ресурсов требуется HTTP.
Сервер слушает только 127.0.0.1, не публикует игру в интернете.
Если Windows запрещает запуск CMD или Node.js, обратитесь к администратору устройства; не отключайте корпоративные ограничения.
