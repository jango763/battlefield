# Battlefield Babylon — Tactical CoH3 direction / 22.11.2026

Цель: самостоятельная мобильная WWII-игра с читаемой тактической камерой, выразительным окружением, рельефом, натуральным PBR, убедительными боями и постановкой уровня Company of Heroes 3. **CoH3 — художественный эталон, не библиотека для копирования платных моделей, текстур или кода.** Исходные GLB наших бойцов остаются своими.

## Реализовано и проверено
- **Камера:** новый дефолт `tactical` (`beta=0.83`, дистанция `23.5`, обзор вперёд `6.5`), плавное слежение. Близкий прежний профиль `classic` включается кнопкой в настройках или `?camera=classic`.
- **Джойстик:** зона 144×144 CSS px; начало жеста — в любой точке круга; десятипроцентная мёртвая зона; аналоговое направление; сброс при `pointerup`, `pointercancel`, потере захвата и `blur`. При движении вверх герой действительно идёт на север.
- **Карта:** существующая 300×300 сохранена, прежние фермы, ДОТы, базы и проходимость не менялись. Локальные органические splat-градиенты для полей, переходы земли и травы, полосы обочины, инстансы живой изгороди и камней, отдельная текстура двух дорожных колей и центральной растительности.
- **Оригинальные ресурсы:** Poly Haven CC0 PBR-сканы, собственные Canvas-текстуры и низкополигональные визуальные элементы; без внешних подписок и runtime SDK.
- **Безопасность кода:** исполняемый `game.js` синхронен с десятью равномерными частями `game.parts`; нет изменения логики движения армий, денег, моделей, оружия и коллизий.
- **Тест:** мобильный Chromium 390×844 DPR=3, два настоящих GLB, старт полноценного боя; ведение стика вверх передвинуло героя с `Z=43` до `Z≈55.3` за удержание. После отпускания движение останавливается. Тест переключения профилей камеры прошёл. GitHub Actions run `45048116535`.

## Критерии дальнейшего художественного развития
1. Реальные неровности рельефа, канавы/берега, не нарушающие логические координаты и стрельбу.
2. Крупные читаемые ориентиры вдоль маршрутов: каменные стены, хозяйственные постройки, руины, разбитая техника.
3. Согласованная гамма грунта/зелени/крыши, дневное освещение, тени контакта, меньше грязных однотонных экранов.
4. Единое визуальное качество всех бойцов/оружия, исправление рук и скиннинга Jakeli, естественный бег.
5. Замеры FPS/DPR на физическом iPhone Safari и в длительных боях с подкреплениями.

Текущий результат — **первый инженерный проход**, не готовый CoH3-уровень. Снимки текущего мобильного кадра просмотрены лично, дороги стали читаемее, но плотности ландшафта, разнообразия зданий и качества теней всё ещё недостаточно. Старый Three.js main не изменён.
