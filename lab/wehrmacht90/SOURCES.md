# Wehrmacht M40 prototype — asset provenance and limits

This folder is an **isolated Babylon.js visual-fitting experiment**. The current model is the original 90-joint civilian reference from `duolahypercho/ar-rifle-demo`, not a completed re-skin of the user's existing 65-joint Panzergrenadier. The legacy Three.js game and `main` are unchanged.

## Actual imported 3D models

- `../../assets/ww2-headwear/m43-field-cap.glb`: M43 cap mesh generated from `Kenton-GMI/muster-ww2/src/assets/germany/infantry/kit/cap.ts`, commit `7d2fa86ebc3b999eaf085831cdcd5dccefea63d4`. **MIT**, copyright © 2026 Kenton Wang. Full text: `../../assets/ww2-headwear/MUSTER-LICENSE.txt`.
- `../../assets/ww2-headwear/field-grey-sidecap.glb`: adapted unmarked sidecap mesh based on `muster-ww2/src/assets/soviet/infantry/pilotka.ts` at the same pinned commit, **MIT**. Soviet star omitted. This is a *stylized* German M34-like sidecap, not an exact historical replica.

These are *real GLB cap meshes* downloaded from assets already checked into the Battlefield repository. They are **not** procedural stand-ins for headgear.

## Uniform and rig

- Uniform M40 palette, pockets, collar, buttons, straps and belt reflect `muster-ww2/src/assets/germany/infantry/uniform.ts`, `palette.ts`, and `webbing.ts` (MIT, same commit). **Important distinction:** the source's 3D tunic itself has not been imported: the preview repaints the existing 90-joint skinned body and builds separately attached garment details inspired by those MIT specifications. The result is a *visual fitting prototype*, not a fully retargeted donor uniform.
- Base 90-joint body: source repository `https://github.com/duolahypercho/ar-rifle-demo`, pinned commit `a6734b81a0679647cf26a30f1a0f6807b8f3b4bc`, `public/characters/civilian-m-01-player-ue5.glb`. The source describes body assets as MakeHuman/MPFB **CC0-1.0**.
- Animations: `public/characters/rifle-motion-ue5-v1.glb` generated by that project's Blender rig; fetched from the same pinned commit. Models and motion GLB are loaded at runtime, **not copied** into Battlefield.
- Original Battlefield German Panzergrenadier is credited under **CC BY 4.0** in `assets/soldiers/CREDITS.md`; **its geometry is not used in this preview**.

## Acceptance

The Playwright workflow `.github/workflows/wehrmacht-wardrobe.yml` checks 90 bones, successfully installed headwear variants, imported meshes, color-painted body, and original animation playback. Browser screenshots should be visually inspected for floating caps, distortion, skin-color boundaries, and garment clipping. **iPhone Safari has not been tested.**
