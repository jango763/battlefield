# Проверки пехоты v2

Из корня репозитория:

```sh
cd tools/infantry-v2
npm install
npm test
```

Нужны Node.js и Python 3. Используется Three.js 0.128.0, совпадающий с версией игры.

`test-rig.cjs` проверяет независимость костей, конечные трансформации, совпадение кистей с хватом оружия, общий масштаб, различия ролей, маску ткани, шесть вариантов оружия героя и скрытие старой брони.

`test-game.cjs` исполняет полный JS исходной и изменённой игры с одинаковым генератором случайных чисел. WebGLRenderer и DOM заменены заглушками, сетевые SDK не выполняются. Сравнивается состояние боя после 30 секунд, включая экономику и здоровье. Проверяет замену всех 46 бойцов и героя. Этот тест не проверяет WebGL, фактический вид материалов, FPS или Safari.

Для дополнительной статической проверки можно запустить `blender -b -t 4 --python render-rig.py`. Нужен Blender с Cycles CPU. Результат является диагностическим рендером геометрии, а не снимком игры в браузере.

Для проверки внешнего вида ролей: `SOLDIER_STATES=role-states.json SOLDIER_RENDER=roles-check.png blender -b -t 4 --python render-rig.py`. Диагностический материал воспроизводит формулу окрашивания ткани, но освещение отличается от игры.
