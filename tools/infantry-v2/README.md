# Проверки пехоты v2

Из корня репозитория:

```sh
cd tools/infantry-v2
npm install
npm test
```

Нужны Node.js и Python 3. Используется Three.js 0.128.0, совпадающий с версией игры.

`test-rig.cjs` проверяет независимость костей, конечные трансформации, совпадение кистей с хватом оружия, лимит моделей, скрытие старой брони и переключение сравнения.

`test-game.cjs` исполняет полный JS исходной и изменённой игры с одинаковым генератором случайных чисел. WebGLRenderer и DOM заменены заглушками, сетевые SDK не выполняются. Сравнивается состояние боя после 30 секунд, включая экономику и здоровье. Этот тест не проверяет WebGL, фактический вид материалов, FPS или Safari.

Для дополнительной статической проверки можно запустить `blender -b -t 4 --python render-rig.py`. Нужен Blender с Cycles CPU. Результат является диагностическим рендером геометрии, а не снимком игры в браузере.
